# Королівство Математики

Браузерна фентезі-RPG для дітей: подорож картою королівства, бої з монстрами
через математичні приклади, магазин аватарів, досягнення й три додаткові
режими тренування. Зараз усі приклади — таблиця множення (2–9); гра
навмисно спроєктована так, щоб надалі прийняти й інші теми математики (див.
`roadmap-kingdom-of-mathematics.md`).

## Що вже є в грі

- **Основна подорож** — карта з 4 регіонів (Ліс Новачків, Гори Хоробрих,
  Замок Майстра, Вежа Мудреця), 12 рівнів-боїв із монстрами, зірки за
  безпомилкове проходження, XP і рівень героя.
- **Магазин** — 16 аватарів за монети, з підтвердженням покупки в окремій
  модалці.
- **Досягнення** — бейджі за перемоги, серії без помилок, повне проходження
  регіонів тощо.
- **Тренування** — три додаткові режими поза основною картою:
  - *Математична пам'ять* — знайди пари "приклад ↔ відповідь".
  - *Лабіринт* — розгалужена мандрівка клітинками з ключами, скринями,
    пастками й порталами; складність зростає з кількістю пройдених спроб.
  - *Перегони* — перегони із двома суперниками; перед стартом гравець сам
    обирає складність (Тренувальний / Пригодницький / Чемпіонський заїзд) —
    кожна дає інший темп суперників і іншу нагороду, а чемпіонський
    відкривається після перемоги у пригодницькому або 5-го рівня героя.
- **Звук** — фонова тема (безшовний луп через Web Audio) і бібліотека з
  36 коротких ефектів, з окремими тумблерами "Музика"/"Звуки" в налаштуваннях
  головного екрана.
- **Єдина дизайн-система** — темно-індигово-фіолетові панелі з тонкою
  золотою рамкою, дві родини кнопок (золота головна / фіолетова другорядна),
  спільна для всіх екранів; головний екран (`MenuScreen.jsx`) — візуальний
  еталон, до якого підтягнуті решта екранів.

## Структура проєкту

```
src/
├── main.jsx                точка входу (монтує App у #root)
├── index.css                Tailwind + шрифти + вся дизайн-система (keyframes, .rpg-panel, кнопки тощо)
├── App.jsx                  стан гри, маршрутизація між екранами
├── version.js                мітка версії/дати останнього оновлення (на головному екрані)
├── data/
│   ├── regions.js            регіони, рівні, монстри, isLevelUnlocked
│   ├── cosmetics.js          аватари магазину
│   ├── rewards.js            бейджі досягнень і щоденні завдання
│   ├── raceDifficulties.js   3 складності "Перегонів" (параметри, нагороди, розблокування)
│   └── raceRivals.js         профілі суперників "Перегонів" по кожній складності
├── game/                     чиста логіка, без React
│   ├── generateQuestion.js   приклади для основної подорожі (класичні + комбіновані)
│   ├── practice.js           приклади для Лабіринту/Перегонів (mix easy/normal/hard)
│   ├── memory.js             генерація карток "Математичної пам'яті"
│   ├── mazeGen.js / mazeQuestions.js   генерація лабіринту і його прикладів
│   ├── raceEngine.js         балансова фізика "Перегонів" (прогрес, наздоганяння, нагороди)
│   ├── music.js / sound.js / sfx.js   фонова музика й бібліотека звукових ефектів
│   ├── progress.js           збереження/завантаження, XP, стрік, квести, історія перегонів
│   └── random.js             rand() і shuffle()
├── components/                перевикористовувані елементи (TopBar, модалки, ArtImage тощо)
└── screens/                   екрани на весь розмір
    ├── MenuScreen, MapScreen, GameScreen, ResultsScreen
    ├── ShopScreen, TrainingScreen
    └── MemoryScreen, MazeScreen, RaceDifficultyScreen, RaceScreen
```

## Запуск локально

Потрібен встановлений [Node.js](https://nodejs.org) (18+).

```bash
npm install
npm run dev
```

Відкриється адреса на кшталт `http://localhost:5173` — гра запуститься
в браузері з "живим" перезавантаженням при зміні коду.

Для збірки готової статичної версії (яку можна викласти на будь-який
хостинг — Vercel, Netlify, GitHub Pages тощо):

```bash
npm run build
```

Результат з'явиться в папці `dist/` (не в репозиторії — вона в `.gitignore`).

## Збереження прогресу й налаштувань

Усе зберігається в **`localStorage`** браузера — прогрес нікуди не зникає
між заходами на тому самому пристрої/браузері:

- `kingdom-multiplication-progress` — основний прогрес (`src/game/progress.js`):
  монети, XP, зірки за рівні, бейджі, історія останніх 5 заїздів "Перегонів"
  (для рекомендації складності), особисті рекорди.
- `musicEnabled`, `musicVolume`, `sfxEnabled`, `sfxVolume` — окремі
  налаштування звуку (`src/game/music.js`, `src/game/sound.js`).
- `raceDifficulty` — остання обрана складність "Перегонів" (лише підказка
  для наступного відкриття — екран вибору показується завжди).

## Графіка й звук

Компонент `ArtImage` (`src/components/ArtImage.jsx`) тихо замінює будь-яку
картинку на emoji-заміну, якщо файл відсутній (404) — нічого не ламається.
Практично всі очікувані файли вже є в `public/assets/`; актуальний перелік
папок і призначення файлів — у `public/assets/README.md`.

Фонова музика — `public/assets/audio/music/`, ефекти — `public/assets/audio/sfx/`.

## Дизайн-система

Головний екран (`MenuScreen.jsx`) — візуальний еталон. Базові класи в
`index.css` (`.rpg-panel` / `.rpg-panel-gold`, `.play-button` /
`.next-challenge-button` / інші кнопки, `.modal-panel` / `.exit-modal-panel`)
перевикористовуються майже на кожному екрані — зміни там автоматично
підхоплюються всюди, тож перед правками панелей/кнопок варто спершу
перевірити, чи не спільний це клас.

## Плани на майбутнє

Повний план розширення теми (від таблиці множення до дробів, рівнянь,
відсотків тощо для 5–6 класу) — у `roadmap-kingdom-of-mathematics.md`.

Що покращити поза темою прикладів (глибина режимів, утримання гравця,
технічна якість, доступність) — у `improvement-plan.md`.

Інші ідеї для продовження:
- Дістати чисту логіку з `game/` (без React) в окремі unit-тести (Vitest/Jest).
- Винести кольори/шрифти з `index.css` у `tailwind.config.js` (`theme.extend`),
  якщо захочеться змінювати палітру з одного місця.
